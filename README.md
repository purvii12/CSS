# 🎨 CSS Practice Repository

This repository contains all my CSS learning and practice work. It includes basic to intermediate examples that demonstrate various CSS concepts such as styling, positioning, layout, transitions, and more.

## 📁 Folder Structure

├── css.html # HTML file linked with external CSS <br>
├── style.css # Main CSS file with various style examples


## ✨ What You'll Find Here

- ✅ Practice with **Selectors** (element, class, ID, pseudo-selectors)
- ✅ Examples of **Box Model**, **Margins**, **Padding**, **Borders**
- ✅ Use of **Flexbox** and **Grid** for layouts
- ✅ Styling **Text**, **Buttons**, and **Forms**
- ✅ Basic **Animations** and **Transitions**
- ✅ Responsive Design basics using **Media Queries**

## 🛠 Technologies Used

- **HTML5**
- **CSS3**
- No frameworks – pure CSS for learning purposes
